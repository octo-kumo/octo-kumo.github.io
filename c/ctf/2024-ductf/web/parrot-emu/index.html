Template Injection

Code inside of templates, have a very limited context, they are missing globals. So we have to find those classes.

Find Classes

{{''.__class__.__base__.__subclasses__()}} ''.__class__ is the str class, <str>.__base__ is the object class, this payload will hence give us all available classes.
